# Acceso a correo y buzones

Configuración de Dovecot para el servicio de acceso al correo de la práctica.

## Contenido

`10-auth.conf` reúne opciones de autenticación; `10-mail.conf` configura aspectos del almacenamiento y acceso a los buzones.

## Uso dentro del proyecto

La carpeta contiene configuración del servicio.
