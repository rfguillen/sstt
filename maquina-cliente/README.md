# Máquina cliente

Archivos de la máquina cliente.

## Contenido

`hosts` y `resolv.conf` corresponden a la resolución de nombres; `ipsec` reúne la configuración del túnel. También se incluyen archivos de certificados y credenciales de la entrega.

## Uso dentro del proyecto

Consulta el [README de IPsec](ipsec/README.md) y la memoria para preparar las pruebas. Las direcciones y los nombres son específicos del escenario.
