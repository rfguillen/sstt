# IPsec · Máquina cliente

Configuración del extremo cliente de la comunicación IPsec utilizada.

## Organización

`ipsec.conf` define las conexiones. Las carpetas `cacerts`, `certs` y `private` reúnen material de autoridades certificadoras, certificados y claves del escenario. En la memoria se indica la autenticación y los parámetros de conexión.

## Reproducción

Revisa las direcciones de ambos extremos, las identidades y las rutas del material criptográfico antes de adaptar la configuración. Utiliza credenciales propias para un nuevo entorno.
