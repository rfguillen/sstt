# IPsec · Máquina servidor

Configuración del extremo servidor de la comunicación IPsec utilizada en la práctica.

## Organización

`ipsec.conf` define las conexiones. Las carpetas `cacerts`, `certs` y `private` reúnen material de autoridades certificadoras, certificados y claves del escenario.
