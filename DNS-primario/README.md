# DNS primario

Configuración BIND del servidor DNS principal del escenario.

## Contenido

`named.conf.local` define la configuración de las zonas; `named.conf.options` reúne las opciones del servicio y `db.fontanerosvillanueva6493.org` contiene los registros de la zona de la práctica.

## Uso dentro del proyecto

Comprueba el dominio, las direcciones de los registros y las rutas de los archivos con la topología de la memoria antes de cargar la configuración.
